# data/

All model inputs. Nothing here is written by `run_pipeline` — the pipeline only
reads from this folder and writes to `results/`.

## Root

| File | Description |
|---|---|
| `population.mat` | Population size of each of the 96 North American locations. |
| `statecodes.mat` | State/province codes and identifiers for the 96 locations (labelling, output formatting). |
| `statecodes.csv` | Same list as CSV, with country and plotting colour — used by `plot_maps_NA.R`. |
| `parafit_vars.mat` | `parafit` (prior parameter samples), `alphamaps` / `betamap` (location → row in `para`), `paramin` / `paramax` (bounds). Regenerate with `make_parafit`. |

## `mobility/`

| File | Description |
|---|---|
| `commutedata.mat` | Commuting network: `nl` (neighbour list), `part` (partition of `nl` per location), `Cave` (average commuting population), `C` (residential population per metapopulation). Used when `Commuting = "n"`. |
| `commutedata_ZEROS.mat` | Same structure with zero commuting — the pure patch model. Used when `Commuting = "p"`. |
| `flightsflow.mat` | Annual air passenger flow `P` between locations, plus `nlp` / `partp`. The model divides by 365 for daily passengers. Used when `flights = "f"`. |

Rebuild both with `build_commutedata` and `build_flightsflow` (see `src/preprocessing/`).

## `incidence/`

| File | Description |
|---|---|
| `dailyincidence_real.csv` | Reported COVID-19 daily incidence, 96 locations × 437 days (20 Jan 2020 – 31 Mar 2021). Used by the real-incidence runs (`truth_id = "tr00"`). |

## `rng_seeds/`

Fixed random draws that make runs reproducible: `fix_para.mat` (initial parameter
draws), `fix_rand_matrix.mat` (state variable initialisation),
`fix_randi_reprobe.mat` (which ensemble members get re-initialised).

## `truths/`

| File | Description |
|---|---|
| `truth_tr01_ls_NY.mat` … `truth_tr35_hs_MX.mat` | The 35 synthetic epidemics (5 transmission rates × 7 seeding locations). Generated by `make_truth`. |
| `all_truths_struct.mat` | All of the above bundled into one struct (`make_truth_grouped_files`). Not tracked — regenerate it. |
| `all_truths_stats.mat` | Onset week, peak week and peak incidence for every synthetic truth (`make_truth_stats_and_histogram`). Read by `make_forecast_metrics`. |
| `real_stats.mat` | The same statistics for the reported COVID-19 data, split by epidemic wave. Read by `make_forecast_metrics_real`. |

## `raw/`

Source matrices the mobility structures are built from:
`final_commuting_matrix_Oct2023.csv`, `Matrix-air-flow-sep04.csv`,
`population_Oct2023.csv`, plus two superseded `.mat` versions kept for reference.
`plot_maps_NA.R` also reads the two matrices directly.

## `gis/` and `air_travel/`

Inputs for the figure scripts: North American political boundaries and location
coordinates (`gis/`), and the Canadian / Mexican / US air passenger tables
(`air_travel/`).

The boundary `.shp` itself is **not** in the repository — see
`gis/shape/README.md` for the download link.
